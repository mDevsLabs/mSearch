# Changelog

## [1.0.0] - 2026-06-24

### Ajouts et Améliorations
- 📁 **Paramètre de téléchargement** : Ajout d'une option pour choisir le dossier de téléchargement par défaut.
- 🚀 **Performances** : Ajout d'un bouton pour activer ou désactiver l'accélération matérielle.
- 📖 **Fonctionnalité Mode Lecture** : Ajout d'une option "Mode Lecture" pour nettoyer les pages web et se concentrer sur le texte.
- 🎨 **Thèmes personnalisés** : Ajout de la possibilité de créer ses propres thèmes de couleurs.
- 🤖 **Amélioration de mAI** : Nouvelles options pour configurer l'assistant mAI (Barre latérale).
- 📂 **Espaces de travail (Workspaces)** : Ajout d'une option pour activer les espaces de travail pour organiser les onglets.
- 🌗 **Vue Scindée (Split View)** : Ajout d'une option pour scinder la vue et afficher deux onglets côte à côte.
- 📺 **Mini-lecteur Vidéo (Picture-in-Picture)** : Ajout d'une option pour lancer automatiquement le lecteur vidéo au changement d'onglet.
- 🥷 **Filtre Anti-Traqueurs Avancé (Privacy Dashboard)** : Ajout d'une option pour activer le tableau de bord de confidentialité anti-traqueurs.

## [0.9.0] - 2026-06-21

### Ajouts et Améliorations
- **Intégration de la barre latérale mAI (mAI Sidebar) 🤖✨ :**
  - Ajout d'une barre latérale rétractable (sliding sidebar) positionnée à droite, chargeant l'assistant mAI (`https://mai-officiel.vercel.app`) via une iframe.
  - Ajout d'un bouton d'accès rapide premium dans la barre de navigation avec le logo mAI (`icons/mai.svg`).
  - Intégration d'une option d'activation/désactivation personnalisable dans les paramètres.
- **Refonte visuelle premium des Paramètres 🎨💎 :**
  - Application d'une esthétique moderne avec effet "Glassmorphism" (transparences et flous d'arrière-plan).
  - Optimisation des espacements, de l'alignement et de la lisibilité des sections de configuration.
- **Amélioration globale de la typographie ✍️🌐 :**
  - Remplacement global des polices d'écriture par défaut par la police élégante **Inter** pour un rendu visuel premium.
- **Traduction du Workflow GitHub Actions ⚙️🇫🇷 :**
  - Traduction intégrale en français et ajout d'emojis descriptifs dans le fichier de workflow `.github/workflows/build-packages.yml`.


## [0.4.0] - 2026-06-19

### Ajouts et Modifications Majeures (Rebranding mSearch)
- **Rebranding complet :** Le navigateur mSearch a été officiellement renommé en **mSearch**.
- **Mise à jour des textes :** Remplacement de "A fast, minimal browser that protects your privacy" par "Avec mSearch, recherchez en toute sécurité !".
- **Modification du protocole interne :** Les URL utilisant `min://` ont été migrées vers `msearch://`.
- **Mise à jour des liens externes :** 
  - Les liens vers les dépôts GitHub ont été remplacés par `mDevsLabs/mSearch`.
  - Les liens X/Twitter pointent désormais vers `@mdevslabs`.
  - Les liens Discord pointent vers `/invite/fV7zwdGPpY`.
  - Les liens de support, de conditions d'utilisation et de documentation utilisent désormais `https://mprojects.odoo.com`.
- **Traductions :** Les fichiers de langue (dont `en-US.json` et `fr.json`) ont été mis à jour pour refléter le nouveau nom.
- **Base de registre (Windows) :** Mise à jour des clés de registre pour le nouveau nom de l'application et les types de fichiers associés.
