# mSearch

> Avec mSearch, recherchez en toute sécurité !

mSearch est un navigateur web simple et léger, conçu pour offrir une expérience de navigation sécurisée et sans distraction.

## À propos

mSearch est un navigateur minimaliste qui met l'accent sur la simplicité et la sécurité. Que vous souhaitiez naviguer rapidement ou effectuer des recherches en toute confidentialité, mSearch vous accompagne.

## Fonctionnalités

- **Navigation sécurisée** — Recherchez en toute tranquillité
- **Léger et rapide** — Une interface simple et réactive
- **Sans distraction** — Concentrez-vous sur l'essentiel
- **Recherche intégrée** — Trouvez ce que vous cherchez facilement

## Installation

Clonez le dépôt sur votre machine :

    git clone https://github.com/mDevsLabs/mSearch.git
    cd mSearch

Installez les dépendances nécessaires :

    npm install
